# System requirements

Status: initial requirements framework

The Unison appliance converts electricity into useful, private household
intelligence. Candidate designs must be modular, serviceable, observable, and
safe to degrade as compute, memory, storage, networking, radio, and sensor
technology changes.

Track requirements for:

- compute and accelerator blades;
- memory capacity and bandwidth;
- redundant local storage and optional provider-blind off-premises backup;
- trusted, guest, management, sensor, and external network boundaries;
- radio and sensor gateways;
- hardware-rooted identity, measured boot, key release, and recovery;
- power delivery, metering, protection, acoustics, cooling, and heat rejection;
- enclosure identity, service access, physical security, and installation;
- accessible setup, status, recovery, and maintenance;
- incremental profiles before the 2027/2028 target generation.

Dedicated circuits, professional installation, and HVAC integration remain
measurement-driven hypotheses, not current requirements.
